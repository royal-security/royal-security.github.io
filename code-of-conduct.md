# Code of Conduct

1. Only hack systems you own or have written permission to test.
2. No unauthorized scanning or attacking third-party networks.
3. No doxing, harassment, or illegal activity.
4. Respect privacy and data protection laws.
5. Report vulnerabilities responsibly.
6. Share knowledge, help others.
7. No leaking team data or tools.

Violation = removal from team.
